# 📱 Установка CamSpec Pro на телефон через GitHub / APK

В этой папке находится актуальный скомпилированный установочный файл приложения **CamSpec Pro**:
- **`CamSpecPro.apk`** — универсальный APK-файл со всеми библиотеками и архитектурами.

Также файл продублирован в папку **`libs/CamSpecPro.apk`** и **`app/libs/CamSpecPro.apk`**.

---

### 🚀 Как скачать и установить с GitHub на телефон:

#### Способ 1: Прямая загрузка файла APK из репозитория
1. Откройте эту папку `apk/` (или `libs/`) в репозитории на **GitHub** прямо со своего смартфона.
2. Нажмите на файл **`CamSpecPro.apk`**.
3. Нажмите кнопку **«Download raw file»** (или «View Raw / Скачать»).
4. После окончания загрузки откройте скачанный файл в уведомлениях или в приложении *«Файлы / Загрузки»*.
5. Нажмите **«Установить»** (если система попросит, разрешите установку приложений из вашего браузера).

### ⚙️ Что нового в этом релизе:
1. **Точное аппаратное перечисление физических сенсоров камер**:
   - Полноценная рекурсивная инспекция `physicalCameraIds` Camera2 API для вычисления реального количества физических объективов устройства.
   - Сбор исчерпывающих оптических параметров (апертура, фокусное расстояние, эквивалент 35 мм, углы обзора FoV, физический размер матрицы, размер пикселя в мкм, аппаратный уровень HAL).
2. **Исправление бага ложного определения «GalaxyCore»**:
   - Полностью устранены неточные регулярные выражения (такие как проверка пробельных подстрок), ошибочно классифицировавшие различные смартфоны как бюджетную серию.
   - Устранены жестко зашитые заглушки: теперь сенсоры 2 Мп и 50 Мп проверяются по производителям (Samsung ISOCELL, Sony Semiconductor, OmniVision Technologies, SmartSens) на основе реального оптического формата и характеристик HAL.
3. **Единая строка верифицированных производителей сенсоров**:
   - Динамическое кросс-сопоставление с базой аппаратных спецификаций для формирования строки подтвержденных поставщиков матриц под конкретную модель устройства.
4. **Двухфакторная система оценки устройства (Dual-Category Rating)**:
   - **Оценка «Цена / Качество» (Value for Money)**: вычисляет сбалансированность и выгоду характеристик относительно ценового сегмента (бюджетный, средний, субфлагман, флагман) с баллами /10 и бейджами выгоды.
   - **Абсолютный рейтинг железа (Overall Hardware Score)**: оценивает чистую производительность процессора, графики, экрана, камер, памяти и батареи без оглядки на цену.
