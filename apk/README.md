# 📱 Установка CamSpec Pro на телефон через GitHub / APK

В этой папке находится актуальный скомпилированный установочный файл приложения **CamSpec Pro** (версия с бесконечным стресс-тестом CPU, стресс-тестом ОЗУ и определением типа матрицы дисплея):
- **`CamSpecPro.apk`** — универсальный APK-файл со всеми библиотеками и архитектурами.

Также файл продублирован в папку **`libs/CamSpecPro.apk`** и **`app/libs/CamSpecPro.apk`**.

---

### 🚀 Как скачать и установить с GitHub на телефон:

#### Способ 1: Прямая загрузка файла APK из репозитория
1. Откройте эту папку `apk/` (или `libs/`) в репозитории на **GitHub** прямо со своего смартфона.
2. Нажмите на файл **`CamSpecPro.apk`**.
3. Нажмите кнопку **«Download raw file»** (или «View Raw / Скачать»).
4. После окончания загрузки откройте скачанный файл в уведомлениях или в приложении *«Файлы / Загрузки»*.
5. Нажмите **«Установить»** (если система попросит, разрешите установку приложений из вашего браузера).

---

#### Способ 2: Сборка свежего APK через GitHub Actions
В репозитории настроен автоматический рабочий процесс `.github/workflows/build-apk.yml`. При каждом пуше изменений в ветку `main` GitHub автоматически собирает APK и выкладывает его в раздел **Releases / Релизы** справа на странице репозитория.

---

### ⚙️ Что нового в этой сборке:
1. **Бесконечный стресс-тест CPU (100% нагрузка всех ядер)**: убран таймер 2 минут, нагрузка идёт непрерывно до ручной остановки, задействованы все Prime, Big и Little ядра.
2. **Стресс-тест оперативной памяти (ОЗУ)**: быстрое физическое заполнение памяти через DirectByteBuffer, мониторинг скорости шины и проверка целостности ячеек.
3. **Тип матрицы экрана**: определение AMOLED, Super AMOLED, LTPO OLED, IPS LCD и подробное описание технологии панели.
4. **Все архитектуры**: `arm64-v8a`, `armeabi-v7a`, `x86_64`.
